# Kivio Dev icon

Independent orange DEV variant of the existing Kivio wave mark. Production assets are unchanged.
Created with the built-in imagegen tool using `../icon.png` as the edit reference. `icon.png` is the saved source; the native formats are generated by Tauri CLI:

```sh
npx tauri icon src-tauri/icons/dev/icon.png --output /tmp/kivio-dev-icons
```

Copy `icon.icns`, `icon.ico` and `32x32.png` from that output into this directory.

Generation prompt: preserve the central two-wave symbol and rounded-square silhouette with transparent outer padding; change the surface to warm amber orange and add crisp dark navy uppercase DEV beneath the mark, legible at Dock size. Keep a clean native application icon without extra decorations.
