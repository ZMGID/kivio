Mode: Operate. Extend Kivio's existing design; user explicitly pins Zotero's library model and asks for complete implementation without staged approvals.

OWN-WORLD: Inherit Kivio semantic tokens, native density, shared buttons, controls and menus. No new visual identity.
STORY: Enter the library, collect sources, correct metadata, classify, search, open a reader, return without losing selection.

FORM: User-pinned Zotero-style three-pane library, extending the existing reading feature; no concept seed required for this explicit reference. Signature interaction: a record opens its source/chat workspace and returns to the same library filters.
