# 聊天页墨墨：体积与运动

2026-10-19。用户确认方向：按三维角色设计，以二维纯色绘制；转头时五官随曲面转动，动作有加速、减速与惯性。范围为聊天空态和流式状态行，不改原生桌宠。

## 参考与取舍

- Grok Bot：观察本机应用的主 Bot、其他角色与工作状态图标。参考简洁色块、两眼与朝向的整体关系；未检查其内部实现，不声称使用相同算法，不复制资产。
- [Zdog](https://zzz.dog/)：三维空间中的几何投影到 Canvas/SVG，保留平面插画风格。采用这一表现原则；现有 SVG 足以承载墨墨，不增加渲染引擎。
- [Rive 2.5D Head Rig](https://rive.app/community/files/2242-4430-25d-head-rig/)：朝向作为独立的连续控制维度。这里只参考创作者示例的目标，不引入 Rive 运行时。
- [Ryan Juckett — Damped Springs](https://www.ryanjuckett.com/damped-springs/)：阻尼振子的解析解、速度连续和帧率独立。基于方程自行实现当前所需的欠阻尼/临界阻尼分支，未复制示例源码。

## 单一计算路径

`任务状态/点击 → KivioBlobSim → 材质空间形体与表情 → projectBlobVolume → SVG`

- `kivioBlobShapes.ts` 继续维护形状和表情词汇。二维轮廓现在是三维体积的截面，不直接作为最终剪影。
- `kivioBlobSim.ts` 维护动作时间、位置/角度对应控制量、速度、目标和阻尼。改变目标保留当前位置与速度；点击叠加有界冲量。逐点形变也保留速度，不重新启动 0→1 的插值时间轴。
- `kivioBlobVolume.ts` 是唯一的曲面和投影计算。身体的深度切片、五官表面坐标使用同一体积；先变形，再俯仰与左右旋转，最后正交投影。两眼逐点投影，曲面法向控制背面裁切，SVG 身体剪裁补齐轮廓边缘。
- `KivioBlob.tsx` 负责输入、SVG 更新和可见性生命周期。已按用户要求移除全局指针监听和跟随接口，仅由任务状态、文案变化及主动点击驱动。所有实例有独立的 SVG 裁切 ID。

## 材质和动作

外观保持蓝色身体、浅色眼睛、无写实光照。球转动时圆形剪影基本不变，曲面五官体现体积；圆角方体的深度截面同样逐渐变方。云团、气泡等装饰性凹陷收拢成柔软的凸体轮廓，避免小图标的自交与闪烁。

挤压沿材质坐标发生：纵向压扁时横向和深度同时扩张，变形缩放的体积保持不变。不同轮廓的深度按截面面积与深度积分近似归一，避免切换形状时体量突增。

朝向以弹簧加速和制动；转向速度带动轻微侧倾与挤压。点击为短促的弹性位移和压缩，连续点击叠加有界速度，位置不重置。眨眼也以连续眼皮状态输出，避免重触发时突然睁眼。任务姿态保留节奏，但减少与转头无关的大幅左右摆动。

## 性能和无障碍

只采样有限的深度截面并输出身体、两眼路径，无 WebGL、纹理或每帧 React 更新。静稳停表；隐藏、失焦、屏外、切会话覆盖期间停止动画。系统减少动态效果变化即时生效，状态表情和点击颜色反馈继续更新。

闲置动作结束后回正停表。运动参数以秒为单位；解析弹簧每帧直接积分，移除相同目标下的重复子步，暂停后的时间步上限避免恢复时暴跳。

## 后续性能优化：准备与复用

按用户要求取消鼠标跟随。当前选择按需准备几何并复用，没有把整个状态动作离线录成动画帧；转向和状态切换仍实时计算，以保留随机动作与中断后的惯性。

每个模拟器只保留一份形体、表情和姿态缓存，生命周期随实例结束，不积累历史帧。先准备体积网格、眼睛曲面坐标及用于法向的差分坐标，再执行旋转投影；轮廓或表情变化时按坐标值失效，正确处理原地修改。同一姿态仅眨眼时复用身体路径，完全相同的几何直接复用结果。形变达到误差阈值后归位并停止逐点积分。首帧在 layout effect 中完成后再交给浏览器绘制。

## 24fps 调度试验（已由下方 60fps 方案替代）

所有尺寸、所有运动状态统一使用 1000/24 ms 的绝对时间节拍。帧间使用 timeout 休眠、到期通过 rAF 对齐屏幕；按原定时间推进下一帧，避免把 timeout 和 vsync 延迟不断累加。迟到时跳过过期节拍，不补帧；动作按真实时间积分。静稳无待办时不保留任何动画计时器，必要的延迟表情结束仍按既有有限唤醒规则处理。隐藏、失焦、屏外、覆盖时暂停，系统减少动态效果继续可用。

24fps 与 60Hz 不整除，展示间隔会交替占 2/3 次屏幕刷新；不声称能获得 120Hz 上每 5 次刷新一帧的完全等间距效果。测试用 60/120/144Hz 虚拟刷新时钟检查 5 秒内 118–120 次动画采样、帧间距有界、失焦不采样、恢复不补帧、回到 idle 后停表。另将转向的帧率一致性验证扩展到 24/30/60/120fps。

53 个定向测试通过，TypeScript、定向 ESLint 和 diff 空白检查通过。演示已更新为同一 24fps 组件。

24fps 最终 macOS bundle 已重启，核对 Chat-B_nMe9go.js 与 dist 一致，原生点击反馈已确认。代码仍未提交、未推送。


## 当前方案：60fps + 附近跟随

用户反馈 24fps 观感不足，统一恢复为最高 60fps。活动期间使用 rAF 与显示器同步，以绝对 1000/60 ms 节拍限制实际模拟和 SVG 更新，不在每帧前等完整定时器，避免错过 60Hz 刷新。高刷屏的多余回调只检查时间；静止停表及隐藏/失焦暂停保持不变，有限唤醒继续使用定时器。

只在局部 data-momo-region（聊天空态区域/演示角色区域）监听鼠标，不监听 window/document 的 pointermove。角色中心半径 max(96px, 0.75×尺寸) 内、空闲时才跟随；离开半径或区域后回正。56px 聊天墨墨半径为 96px；28px 状态图标不跟随。无透明覆盖层，不拦截附近输入框和文字。连续鼠标事件不取消已排队的帧，避免输入频繁时动画被饿死。点击优先于原有跟随目标。

54 个定向测试通过，包括 60/120/144Hz 下 5 秒 298–300 帧、暂停恢复、局部/远处鼠标行为、离开回正停表和小图标不跟随。TypeScript、定向 ESLint、diff 检查通过。最终 macOS bundle Chat-C62J2PIg.js 与 dist 一致，重启后已观察到靠近时右上转向。演示同步更新，代码未提交/未推送。


## 空闲角色的小动作

大尺寸聊天角色新增五类低频动作：眨眼、侧望、抬眼思考、低头看一眼、轻歪头。首次约 2.2–4.2 秒，后续每 6–12 秒尝试一次，不连续重复同一类；前一动作未回稳或点击余热未散时跳过。转向/歪头停留约 1.3–2.3 秒再回正。鼠标接管朝向时停止自主调度，离开后重新安排；点击、文案轻提示延后自主动作。小状态图标不启用自主动作，减少动态效果下禁用。

静止间歇不跑 rAF，只有一次未来唤醒；隐藏/失焦仍清理定时器，不累计待播放动作。新增测试覆盖自主动作触发、休息、鼠标优先、减少动态效果，以及鼠标恰好在正中离开时仍能恢复自主调度。此前提交 4ce1afe6 保持不变，本次增量尚未提交。
