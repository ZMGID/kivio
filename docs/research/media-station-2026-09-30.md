# 媒体站：调研与首版实现

需求：在「扩展」中提供专门生图、生视频的创作入口。调研日期：2026-09-30。

## 产品参考与取舍

| 官方资料 | 观察 | 本次采用 |
| --- | --- | --- |
| [Runway 生成视频入门](https://help.runwayml.com/hc/en-us/articles/37425232841875-Getting-Started-with-Generative-Video) | 文生视频和图生视频共用创作流程，生成结果有组织地保留 | 图片 / 视频切换、描述、可选参考图、独立历史 |

补充 Exa 定向搜索 1 组、5 个结果，筛选官方来源；结合 Runway、BFL 与 xAI 的官方指南。此为面向首版实现的流程调研，并非模型质量或价格评测。

初版采用「左侧参数 + 右侧作品记录」，根据 UI 反馈改为「上方横向创作区 + 下方作品记录」：常用参数在同一页，结果可直接预览、另存、搜索和复用。首版不做节点工作流、时间线剪辑或自动多镜头拼接。它们会引入与单次媒体生成不同的状态生命周期。

## 实现归属与支持范围

- 原路径：生图通过聊天主模型 / Mixer 工具；没有独立媒体任务。新路径：媒体站 → typed IPC → `chat::media_station` → 既有 `image_generation` 或 xAI 视频请求。
- 唯一负责人：Rust `MediaStation` 持有任务、停止信号、终态与磁盘记录。新增模块收拢离页仍继续运行的任务生命周期；页面只保留未提交草稿。没有新增通用编排框架，也没有迁移或删除现有聊天生图入口。
- 生图：沿用现有供应商端点、认证、代理、参考图和画幅规则，每次一张；建议模型来自既有能力元数据，未知新模型可手填。
- 视频：首版仅支持 xAI `/videos/generations` + `/videos/{request_id}` 协议及兼容服务，API Key 认证，720p，5 / 10 / 15 秒，最多一张首帧。不宣称支持 Sora、Runway、Veo 原生视频协议。
- 视频创建不会自动重发，防止超时后重复计费；等待上限 15 分钟，下载上限 128 MB。用户显式再次点击生成才创建新任务。
- 最多三个并发任务。离开页面不取消；停止等待只终止本地请求，不声称取消供应商计费。应用退出后的未完成任务在下次读取时标为中断，不自动重复提交。
- 历史及结果存于应用数据目录 `media-station/<uuid>/`，JSON 原子写入，列表只传元数据与图片缩略图；选中结果才读取完整媒体，离开预览释放 Blob URL。
- 复用全局 Button / IconButton、Input / Select / TextArea、主题 token 和 custom-scrollbar。路由词汇仍由 routeContract.json 同时约束前后端，IPC 类型通过原有 protocol:generate 生成。

## 验证与限制

前端行为测试覆盖重复提交、失败后重试、草稿离页重开、后台任务可观察状态、停止等待和历史读取错误。路由测试覆盖媒体站不被解析成对话 ID。Rust 测试覆盖参数、视频状态、重启恢复，以及本地 HTTP 模拟生图服务的请求和真实输出保存。

浏览器检查覆盖宽 / 窄窗口与主题；浏览器本身没有 Tauri IPC，实际付费生成仍需在桌面应用中使用已配置的供应商验证。未运行真实付费图片 / 视频生成，未验证完整桌面打包。视频进程重启后不自动恢复供应商轮询；模型支持范围和计费由所选服务决定。

验收记录：92 项前端 / 路由测试、4 项 Rust 媒体测试通过；架构检查与前端构建通过。宽屏 1440×1000、窄屏 900×800、深色主题以及视频画幅下拉已人工检查。

UI 修订：去掉高耸侧栏表单、大块虚线空态与重复说明；提示词横向展开，参数同排，参考图与生成操作在同一底栏。复用原有全局控件，仅修改展示布局；相关 5 项行为测试、TypeScript、ESLint 通过，浏览器验证常规 / 窄窗口和视频画幅菜单。
