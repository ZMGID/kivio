# 媒体站：调研与首版实现

需求：在「扩展」中提供专门生图、生视频的创作入口。调研日期：2026-09-30。

补充 Exa 定向搜索 1 组、5 个结果，筛选官方来源；结合 Runway、BFL 与 xAI 的官方指南。此为面向首版实现的流程调研，并非模型质量或价格评测。

初版采用「左侧参数 + 右侧作品记录」，根据 UI 反馈改为「上方横向创作区 + 下方作品记录」：常用参数在同一页，结果可直接预览、另存、搜索和复用。首版不做节点工作流、时间线剪辑或自动多镜头拼接。它们会引入与单次媒体生成不同的状态生命周期。

## 实现归属与支持范围

- 原路径：生图通过聊天主模型 / Mixer 工具；没有独立媒体任务。新路径：媒体站 → typed IPC → `chat::media_station` → 既有 `image_generation` 或 xAI 视频请求。
- 唯一负责人：Rust `MediaStation` 持有任务、停止信号、终态与磁盘记录。新增模块收拢离页仍继续运行的任务生命周期；页面只保留未提交草稿。没有新增通用编排框架，也没有迁移或删除现有聊天生图入口。
- 生图：沿用现有供应商端点、认证、代理、参考图和画幅规则，每次一张；建议模型来自既有能力元数据，未知新模型可手填。
- 视频：首版仅支持 xAI `/videos/generations` + `/videos/{request_id}` 协议及兼容服务，API Key 认证，720p，5 / 10 / 15 秒，最多一张首帧。不宣称支持 Sora、Runway、Veo 原生视频协议。
- 视频创建不会自动重发，防止超时后重复计费；等待上限 15 分钟，下载上限 128 MB。用户显式再次点击生成才创建新任务。
- 最多三个并发任务。离开页面不取消；停止等待只终止本地请求，不声称取消供应商计费。应用退出后的未完成任务在下次读取时标为中断，不自动重复提交。
- 历史及结果存于应用数据目录 `media-station/<uuid>/`，JSON 原子写入，列表只传元数据与图片缩略图；选中结果才读取完整媒体，离开预览释放 Blob URL。
- 复用全局 Button / IconButton、Input / Select / TextArea、主题 token 和 custom-scrollbar。路由词汇仍由 routeContract.json 同时约束前后端，IPC 类型通过原有 protocol:generate 生成。

## 验证与限制

前端行为测试覆盖重复提交、失败后重试、草稿离页重开、后台任务可观察状态、停止等待和历史读取错误。路由测试覆盖媒体站不被解析成对话 ID。Rust 测试覆盖参数、视频状态、重启恢复，以及本地 HTTP 模拟生图服务的请求和真实输出保存。

浏览器检查覆盖宽 / 窄窗口与主题；浏览器本身没有 Tauri IPC，实际付费生成仍需在桌面应用中使用已配置的供应商验证。未运行真实付费图片 / 视频生成，未验证完整桌面打包。视频进程重启后不自动恢复供应商轮询；模型支持范围和计费由所选服务决定。

验收记录：92 项前端 / 路由测试、4 项 Rust 媒体测试通过；架构检查与前端构建通过。宽屏 1440×1000、窄屏 900×800、深色主题以及视频画幅下拉已人工检查。

UI 修订：去掉高耸侧栏表单、大块虚线空态与重复说明；提示词横向展开，参数同排，参考图与生成操作在同一底栏。复用原有全局控件，仅修改展示布局；相关 5 项行为测试、TypeScript、ESLint 通过，浏览器验证常规 / 窄窗口和视频画幅菜单。

UI 修复（2026-10-04）：创作页按生图 / 生视频分别记住本次结果；切换到尚无结果的类型时显示该类型的灵感引导，不再沿用另一类型的结果卡片。收起仅影响当前类型，离页重开保留各类型的结果；异步提交返回按任务类型更新，避免切换后串入另一类型。行为回归覆盖切换、迟到提交、收起与重开；浏览器使用模拟 API 的真实页面组件验证结果切换，未执行桌面实机或付费生成。

UI 扁平化（2026-10-04）：创作结果区移除外层卡片、标题 / 操作栏分隔线及内部滚动，预览、状态、描述和操作直接排在页面中；历史详情继续使用原弹窗。生成占位画布按视口高度限制尺寸，窄屏等待状态允许换行，避免停止操作被挤出或遮挡。浏览器模拟 API 验证 1440×900 浅色、600×700 深色的生成中 / 完成态及历史详情弹窗；窄屏停止按钮位于底部输入区之上，无横向溢出。未执行桌面实机或付费生成。

作品库接入（2026-10-04）：原作品列表只导入聊天交付文件，且过滤掉没有来源聊天的记录，导致媒体站生成结果不可见。现在作品库负责人 `chat::artifacts` 在历史导入时读取 `media-station/<uuid>/job.json`，将已完成的每个输出按稳定 ID 登记到既有索引；新旧媒体结果共用原文件，不复制原图或视频，不改变媒体任务生命周期。媒体作品不依赖聊天存在，来源显示为媒体站，不提供无效的回到聊天操作；重命名保持，删除通过既有 tombstone 防止再次导入。运行中、失败或停止的任务不作为已完成作品导入。

验证：15 项 Rust artifact 测试、9 项作品页测试、TypeScript、修改文件 ESLint 和架构检查通过；回归覆盖图片、视频从运行到完成、源路径与导出内容、重命名 / 删除后重导入、缺失文件恢复及异常历史隔离。另用本机已有的 4 张生成图片在临时作品索引中实际导入和逐字节导出校验，0 项警告，并将该后端结果用于浏览器检查缩略图、媒体站来源、列表搜索和文件打开请求的原路径；真实作品索引和原文件未修改。未验证桌面默认应用打开或付费生成；后端修复需重新构建 / 启动开发版后生效。

桌面实机补验（2026-10-04）：用户反馈前端文案更新后仍只有 2 件作品。检查发现运行中的开发版后端自 10 月 3 日 19:55 起未重启，可执行文件也是旧构建；前端热更新不代表 Rust 修复已加载。构建最新 `kivio` 后，经用户授权退出旧实例并重启开发版，真实桌面作品页自动显示 6 件作品（2 件聊天文件 + 4 张媒体站图片）；点击图片筛选后显示 4 张原有生成图，缩略图与媒体站来源正常。实机截图：`/tmp/kivio-works-live.png`、`/tmp/kivio-works-images-live.png`。底部原有 1 项历史导入警告仍保留，4 张媒体图片均已入库；未新增或调用付费生成。

创作管理（2026-10-04）：创作记录增加选择模式、全选当前筛选结果、单条与批量删除。确认后永久清理该任务的源文件和作品索引，保留导出副本；源文件被其他创作引用时，该引用可能失效。生成中任务须先停止本地等待再删除；停止等待不保证取消供应商任务或退款。删除接口逐条返回成功和失败，失败项保留选择并显示错误，部分文件清理失败保留任务元数据供重启后重试；迟到刷新和旧运行结果不得恢复已删除记录。状态与运行生命周期仍由 `MediaStation` 后端负责，文件与关联索引的删除在 `artifacts` 中串行化处理，锁顺序为媒体任务状态 → 作品索引。

图片详情增加每个输出的“继续编辑”，以选中图片作参考图带回原描述、供应商、模型和画幅；视频详情的“修改参数 / 重新生成”带回原请求。用户需手动点击生成，新请求按供应商计费；不覆盖旧作品，也不提供视频剪辑。复用全局确认弹窗、按钮、输入与选择控件；页面不覆盖输入框和下拉菜单基础样式。

验证：30 项前端测试（媒体站 21、作品页 9）和 27 项 Rust 测试（媒体任务 7、作品索引 20）通过；TypeScript、协议生成一致性、修改文件 ESLint、架构检查通过。浏览器验证 600×700 深色与 1440×900 浅色选择布局、取消确认不删除、部分失败保留未删选中项和错误、视频重生成不自动提交。重新构建并启动开发桌面后，以本机编码的两条临时 PNG/MP4 记录实际执行批量删除，确认两目录与两作品记录消失、两导出副本保留，作品数由 8 回到 6，原有 4 张生成图保留；实机继续编辑图片已带入参考图及原参数，视频已带回描述、画幅和时长。无付费生成请求。截图：`/tmp/kivio-media-edit-image.png`、`/tmp/kivio-media-edit-video.png`、`/tmp/kivio-media-batch-selected.png`、`/tmp/kivio-media-batch-deleted.png`、`/tmp/kivio-media-delete-works.png`。临时验证页面与源记录已清理。

删除后再次重启桌面，媒体站仍只有原有 4 条创作，临时记录未恢复；清理导出验证副本与临时草稿，最终停留在带“选择记录”入口的创作记录页（`/tmp/kivio-media-management-final.png`）。开发前端服务保持运行供该桌面实例继续使用。

直接选择交互收敛（2026-10-04）：移除“选择记录 / 退出选择”及选择模式状态。卡片角上的全局图标按钮始终可勾选，卡片主体独立打开详情；选中项存在时显示批量删除栏，取消最后一项后自动收起，无需退出模式。全选当前筛选结果可直接使用，运行中记录仅禁用勾选，详情仍能打开以停止等待。21 项媒体站测试、TypeScript 和修改文件 ESLint 通过；浏览器实跑证明直接勾选不打开详情、选中时仍可打开/关闭详情并保留勾选、取消最后一项收起批量栏、全选跳过运行中记录，验证浅色宽屏与深色窄屏布局。当前真实桌面历史及源目录均已空，因此实机仅验证热更新后的空态与直接全选入口（`/tmp/kivio-media-direct-grid.png`），卡片交互在生产页面组件的临时浏览器场景验证；未改动用户记录或调用生成，临时页面已清理。
