## 边界

- 自动触发使用内存中的 96K 测试窗口，阈值为 80952 token；没有修改用户供应商配置，也不表示 DeepSeek 的原生窗口是 96K。
- 大部分输入是可舍弃的过期诊断记录，约 99% 的缩减只说明这些夹具的效果，不能外推为实际会话的常见压缩率。数字是应用估算，不是服务商计费量。
- 快照恢复通过实际 `ConversationContextSummary` JSON 序列化/反序列化及恢复后的模型请求验证；不是本轮桌面冷启动测试。历史工具调用和结果是夹具，没有真的读取用户文件。
- 取消检查验证本地返回取消及输入未变，不代表服务商已停止远端计算或计费。
- 本轮没有人为触发服务端硬窗口错误、429、断网，也没有执行桌面 UI 队列压力测试。超窗终态及耗尽回退仍由此前真实适配器加本地 SSE 故障回归覆盖，不将其算作供应商实机故障测试。

## 复跑

环境变量只提供设置路径、供应商 ID 和模型；API key 在测试进程内从该供应商配置读取，不打印、不写入结果。

```powershell
$env:KIVIO_COMPACTION_LIVE_SETTINGS = Join-Path $env:APPDATA 'com.zmair.kivio/settings.json'
$env:KIVIO_COMPACTION_LIVE_PROVIDER = '<本机 DeepSeek 供应商 ID>'
$env:KIVIO_COMPACTION_LIVE_MODEL = 'deepseek-flash'
$env:KIVIO_COMPACTION_LIVE_REPORT = Join-Path $env:TEMP 'kivio-compaction-stress.json'
cargo test --manifest-path src-tauri/Cargo.toml --lib live_deepseek_compaction_stress -- --ignored --nocapture
```
