# Kivio Desktop v2.9.10 — 测试版 / Pre-release

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

此版本用于测试。请在使用中反馈遇到的问题。This is a pre-release for testing and feedback.

## 下载 / Downloads

- **Windows 安装包 / Installer** — `Kivio.Desktop_2.9.10_x64-setup.exe`（NSIS）
- **Windows 便携版 / Portable** — `Kivio.Desktop_2.9.10_x64-portable.zip`，解压后运行 `Kivio Desktop.exe` / unzip and run.
  - 需要 Edge WebView2，设置和对话与安装版共用。Requires Edge WebView2; settings and conversations are shared with the installed app.
- **macOS** — `Kivio.Desktop_2.9.10_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`。
  - First launch: right-click → Open, or run the command above.

## 本次变化 / What's New

以下整理 **v2.9.9 → v2.9.10** 的主要变化。These are the main changes since v2.9.9.

- **文件引用 / File references** — 后续回复可再次引用同一对话中较早生成的文件；文件链接改为紧凑的行内展示，并支持从文件菜单定位文件。Later replies can open files created in earlier turns of the same conversation; file links are more compact, with an action to reveal the file.
- **聊天运行 / Chat runs** — 改进取消、切换对话、预览交接和中断后的状态处理，减少迟到结果覆盖当前对话的风险。Improve cancellation, conversation navigation, preview handoff and interrupted-run state handling so late results do not overwrite the current conversation.
- **设置与工具 / Settings and tools** — 改进设置并发保存与窗口关闭流程，恢复插件管理，并加入计算机工具更新入口。Improve concurrent settings saves and window closing, restore plugin management, and add an update path for computer tools.
- **Lens 与 Windows / Lens and Windows** — 改进 Lens 截图与窗口切换的可靠性；调整 Windows 图标、通知身份和启动行为。Improve Lens capture and window transitions; refine Windows icons, notification identity and startup behavior.
- **自动化与内部结构 / Automations and internals** — 整理聊天、Lens、设置及自动化的流程归属，补充架构边界和回归检查。Clarify ownership of chat, Lens, settings and automation flows, with additional architecture and regression checks.
