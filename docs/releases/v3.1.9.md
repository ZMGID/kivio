# Kivio Desktop v3.1.9

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows 安装包 / Installer** — `Kivio.Desktop_3.1.9_x64-setup.exe`（NSIS）
- **Windows 便携版 / Portable** — `Kivio.Desktop_3.1.9_x64-portable.zip`，解压后运行 `Kivio Desktop.exe` / unzip and run.
  - 需要 Edge WebView2，设置和对话与安装版共用。Requires Edge WebView2; settings and conversations are shared with the installed app.
  - 应用内更新仍下载安装包；继续使用便携版请手动下载新 ZIP。In-app updates download the NSIS installer; download the new ZIP manually to remain portable.
- **macOS** — `Kivio.Desktop_3.1.9_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`。
  - First launch: right-click → Open, or run the command above.

## 新版本亮点 / What's New

以下是 **v3.1.8 → v3.1.9** 的变更。These changes cover **v3.1.8 → v3.1.9**.

- **Keenable 网页搜索 / Keenable web search** — 新增 Keenable 搜索供应商，无需 API Key 即可使用，也可选填密钥。Add the Keenable search provider, usable without an API key, with an optional key.
- **项目工作区与 PR / Project workspace and pull requests** — 标题栏工作区面板支持分支切换、Git 操作、worktree 环境、用量与发布入口；右侧新增 PR 面板，可搜索筛选、查看检查与评审、切换到 PR 分支及创建当前分支的 PR。Add a titlebar workspace panel for branch switching, Git actions, worktree environments, usage and publishing, plus a right-side pull request panel with search, filters, checks, reviews, checkout and PR creation.
- **子代理协作 / Sub-agent collaboration** — 重做任务派发、后台等待、代理消息与结果投递；聊天时间线统一显示子代理的运行状态和回答，右侧可查看代理对话，改善取消、恢复及迟到结果隔离。Rework task delegation, background waiting, agent messages and result delivery. Show sub-agent status and replies in the chat timeline, expose their conversations in the side panel, and improve cancellation, recovery and late-result isolation.
- **规划与目标 / Plans and goals** — 用 `/plan` 与 `/goal` 发起规划和持续目标，替代原输入栏模式选择；根据模型能力控制子代理委派规模。Start plans and persistent goals with `/plan` and `/goal` instead of the former composer mode picker, and adjust delegation limits to model capabilities.
- **媒体创作 / Media creation** — 重做图片与视频创作界面，区分当前画布和创作记录，新增灵感预设、描述筛选及作品复用；图片可作为后续创作的参考，原作品保留。Redesign image and video creation with a separate canvas and history, idea presets, prompt search and output reuse. Use an image as a reference for a new creation while retaining the original.
- **侧栏、引导与动效 / Sidebar, onboarding and motion** — 重做首次配置引导、对话列表和集编辑；统一文件图标、链接图标、下拉框和弹窗动效，改善面板切换、跟随滚动及输入栏反馈。外部 CLI 沙箱选择移到标题栏，新增 Grok 用量环和无缝 6×4 用量条。Redesign first-run setup, conversation lists and set editing. Unify file and link icons, select and dialog motion, and improve panel transitions, follow scrolling and composer feedback. Move the CLI sandbox picker to the titlebar and add a Grok usage ring and seamless 6×4 usage strip.
- **技能与 MCP / Skills and MCP** — 重做技能与 MCP 管理页，加入搜索、筛选和详情；聊天与语音共用按凭据隔离工具权限的 Kivio-server，MCP 列表支持服务图标。低频内置工具改为按需加载。Refresh skill and MCP management with search, filters and details. Share Kivio-server between chat and voice with credential-scoped tool access, display server icons, and load low-frequency built-in tools on demand.
- **外部 CLI / External CLIs** — 改善原生会话导入、终端结果、权限确认与进程清理，设置和格式写入不再触发无关重连；先显示已有模型快照并在后台刷新。OpenCode 按模型提供真实思考档位，切换模型后再应用对应配置。Improve native-session imports, terminal results, approvals and process cleanup, avoid unrelated reconnects after settings or formatting writes, and show saved model lists during refresh. Read OpenCode's per-model reasoning variants and apply their configuration after model selection.
- **Agent SDK 与历史分支 / Agent SDK and history branches** — 提供可独立使用的 Rust Agent SDK，统一模型、工具、技能、MCP、会话与执行控制；桌面聊天使用同一运行时，持久保存会话分支及失败或多模型回答历史。Provide a standalone Rust Agent SDK for models, tools, skills, MCP, sessions and run control. Use the same runtime in desktop chat and persist session branches, including failed and alternate model answers.
- **精简功能 / Removed features** — 移除作品库和内置专家助手；旧的作品页链接回到聊天。设置页侧栏不再提供折叠按钮。Remove the Works library and built-in expert assistants; old Works links fall back to chat. The settings sidebar no longer has a collapse toggle.
- **聊天可靠性 / Chat reliability** — 修复消息重叠和 Windows 发送时的栈溢出；改善流式文字展示、空回答恢复、上下文压缩及输出上限处理。对话目录读取失败时保留已加载数据并报告错误，避免错误清理；修正 Agent 提示词冲突，Chat 模式允许 HTML 页面工具。Fix overlapping messages and Windows send-time stack overflows. Improve streamed text, empty-response recovery, context compaction and output limits. Retain loaded conversations and report directory-read failures instead of unsafe cleanup, resolve Agent prompt conflicts, and allow HTML page tools in Chat mode.
- **配置恢复与备份 / Configuration recovery and backup** — 旧配置中不兼容的字段不再导致整份设置回退，写入前保留恢复副本；未配置的模型选择保持为空。本地与 WebDAV 备份仅包含设置、供应商、模型、助手和集配置，不再备份或恢复对话、附件、项目与 worktree 文件。Recover compatible settings sections when an old field is incompatible and preserve a recovery copy before saving. Keep unconfigured model selections empty. Local and WebDAV backups contain settings, providers, models, assistants and sets, excluding conversations, attachments, projects and worktree files.
- **ACP 终端 / ACP terminal** — 通过登录 Shell 执行命令，合并插件 PATH 并校验工作目录；含空格的可执行文件路径可直接运行。Run commands through the login shell, merge plugin PATH, validate the working directory, and execute paths containing spaces directly.
- **模型库 / Model catalog** — 内置模型库更新至 `2026-11-11.1`，补充 Claude Fable/Mythos 5.2、Gemini 4 Carbon、GPT Image 2.6 等型号的能力、上下文、思考档位和价格资料，保留用户覆盖优先级。Refresh the bundled catalog to `2026-11-11.1` with capabilities, context limits, reasoning levels and pricing for Claude Fable/Mythos 5.2, Gemini 4 Carbon, GPT Image 2.6 and other models, while preserving user overrides.
- **依赖安全 / Dependency security** — 升级 MCP 和 SQLite 依赖，修复 HTTP 响应无界缓冲、工具缓存和 OAuth 地址校验漏洞，以及异常 WAL 文件引发的内存数据泄露风险；将 `calamine` 升级到 0.38，修复畸形 xlsx 解析导致的崩溃和内存耗尽。Update MCP and SQLite dependencies to fix unbounded HTTP response buffering, tool-cache and OAuth address-validation vulnerabilities, and memory disclosure from malformed WAL files. Upgrade `calamine` to 0.38 to fix crashes and unbounded allocation when parsing malformed spreadsheets.
- **构建一致性 / Consistent builds** — 发版在线模型库不可用时回退到已校验的内置快照，macOS 与 Windows 使用同一模型快照。Fall back to the validated bundled catalog when the online model database is unavailable and use one snapshot on macOS and Windows.

## 验证边界 / Validation limits

- 自动化检查不替代桌面实机验收；Windows/macOS 安装升级、真实备份恢复和上游 CLI 服务仍需按实际环境验证。Automated checks do not replace desktop acceptance; installation and upgrades, real backup restores, and upstream CLI services still require validation in their target environments.
- macOS DMG 和 Windows EXE 未签名，便携版的应用内更新仍使用安装包。The macOS DMG and Windows EXE are unsigned; in-app updates from the portable edition still use the installer.
