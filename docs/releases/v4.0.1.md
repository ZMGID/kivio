# Kivio Desktop v4.0.1

## 下载 / Downloads

- Windows 安装包 / Installer：`Kivio.Desktop_4.0.1_x64-setup.exe`（NSIS）。
- Windows 便携版 / Portable：`Kivio.Desktop_4.0.1_x64-portable.zip`。解压后运行 `Kivio Desktop.exe`。Unzip and run `Kivio Desktop.exe`.
  - 需要 Microsoft Edge WebView2。便携版与安装版共享设置和会话。Requires Microsoft Edge WebView2. The portable and installed editions share settings and conversations.
  - 应用内更新会下载 NSIS 安装包。继续使用便携版时，请手动下载新版 ZIP。In-app updates download the NSIS installer. To keep using the portable edition, download the new ZIP manually.
- macOS（Apple Silicon）：`Kivio.Desktop_4.0.1_aarch64.dmg`。应用使用临时签名，未公证。The app is ad-hoc signed and unnotarized.
  - 首次启动可右键选择「打开」。如果 macOS 仍阻止启动，可运行 `xattr -cr "/Applications/Kivio Desktop.app"`。On first launch, right-click the app and choose Open. If macOS still blocks it, run the command above.

## 新版本亮点 / What's New

- **代理与模型选择 / Agent and model selection**。在同一菜单选择代理、模型和推理强度。在一条对话中切换代理时，可以交接已有上下文。Choose the agent, model, and reasoning effort in one menu. Carry context forward when switching agents within a conversation.
- **专家与项目 / Experts and projects**。新增 20 个内置专家，可收藏、自定义并配置默认知识库。新建项目支持克隆 Git 仓库，聊天输入栏支持补全项目文件、技能和命令。Save or customize 20 built-in experts and configure their default knowledge bases. Clone a Git repository when creating a project. Complete project files, skills, and commands in the chat composer.
- **供应商登录 / Provider sign-in**。设置中提供 ChatGPT 登录与 Codex OAuth 两种供应商授权方式。供应商列表显示账号和登录状态。Settings offer ChatGPT Sign In and Codex OAuth as separate provider options. The provider list shows account and sign-in status.
- **CLI 账号与额度 / CLI accounts and limits**。额度面板展示支持的 CLI 的套餐和重置时间，新增 Kimi 与 Antigravity 额度。按项目隔离额度缓存和会话启动身份，macOS 优先使用登录 Shell 的路径。The limits panel shows plan and reset information for supported CLIs and adds Kimi and Antigravity limits. Scope quota caching and session launch identity by project. On macOS, prefer the login shell's path.
- **聊天加载与显示 / Chat loading and display**。按窗口加载长对话历史，切回时复用快照并恢复阅读位置。修复流式自动跟随、工作记录与最终回答的分组，并让 HTML 预览按内容调整高度。Load long histories in windows and reuse snapshots to restore reading position. Fix follow scrolling during streaming, group work records separately from final answers, and size HTML previews to their content.
- **搜索与知识库 / Search and knowledge bases**。重排网络搜索设置，新增 DeepSeek 以图搜索，修复知识库检索、引用与索引恢复。Reorganize web search settings, add reverse image search through DeepSeek, and fix knowledge base retrieval, citations, and index recovery.
- **连接与备份 / Connections and backups**。修复 Antigravity 断流后的会话恢复与 Codex npm 安装的原生语音组件定位。对模型过载统一重试，并修复 WebDAV 大备份上传超时。Fix Antigravity session recovery after a disconnect and locate native voice components for npm-installed Codex. Apply consistent retries for overloaded models and fix timeouts during large WebDAV backup uploads.
- **模型库与依赖 / Model catalog and dependencies**。更新内置模型库，并升级桌面应用的 Cookie 与 URL 依赖以修复安全问题。Update the bundled model catalog and upgrade the desktop app's cookie and URL dependencies to address security issues.
