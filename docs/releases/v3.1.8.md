# Kivio Desktop v3.1.8

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows 安装包 / Installer** — `Kivio.Desktop_3.1.8_x64-setup.exe`（NSIS）
- **Windows 便携版 / Portable** — `Kivio.Desktop_3.1.8_x64-portable.zip`，解压后运行 `Kivio Desktop.exe` / unzip and run.
  - 需要 Edge WebView2，设置和对话与安装版共用。Requires Edge WebView2; settings and conversations are shared with the installed app.
  - 应用内更新仍下载安装包；继续使用便携版请手动下载新 ZIP。In-app updates download the NSIS installer; download the new ZIP manually to remain portable.
- **macOS** — `Kivio.Desktop_3.1.8_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`。
  - First launch: right-click → Open, or run the command above.

## 新版本亮点 / What's New

以下是 **v3.1.7 → v3.1.8** 的变更。These changes cover **v3.1.7 → v3.1.8**.

- **页面回复 / Page replies** — 新增对话内 HTML 页面展示与截图预览，可呈现图表、示意图和界面草图；页面跟随主题并按内容适配高度。Add inline HTML pages and screenshot previews for charts, diagrams, and mockups, with theme-aware styling and content-based sizing.
- **语音编排 / Voice orchestration** — 增加语音舞台与编排入口，改善 Codex 语音会话恢复、挂断和资源清理。Add a voice stage and orchestration entry point, and improve Codex voice recovery, hangup, and resource cleanup.
- **外部 CLI / External CLIs** — 更新 Claude、Codex、ACP、Pi 与 Grok 的适配，改善原生会话、交互确认和运行状态同步。Update Claude, Codex, ACP, Pi, and Grok adapters for native sessions, interaction acknowledgements, and run-state synchronization.
- **用量与费用 / Usage and costs** — 输入栏新增像素用量条与悬停详情；外部 CLI 费用按整轮累计，上下文继续使用最近一次请求口径。Add a pixel usage strip with hover details; accumulate external CLI costs across the whole turn while keeping context usage tied to the latest request.
- **聊天阅读 / Chat reading** — 将工具活动收拢为紧凑摘要，减少过程播报和分页打断；改善对话切换、错误摘要及文本选择反馈。Group tool activity into compact summaries, reduce process narration and pagination interruptions, and improve conversation switching, error summaries, and text selection.
- **侧栏与工作区 / Sidebar and workbench** — 统一标题栏与侧栏图标，增加 Dock 面板入口和关闭操作，并调整设置导航与输入栏布局。Align titlebar and sidebar icons, add Dock panel launchers and close actions, and refine settings navigation and composer layout.
- **技能精简 / Simpler bundled skills** — 默认仅附带 Kivio 配置指南和自动化工作流两个技能；支持同名项目或个人技能覆盖附带版本，移除按固定技能名选择和强制加载的逻辑。Ship only the Kivio configuration and automation skills by default, allow project or personal overrides, and remove name-specific skill selection and forced-loading instructions.
- **模型与构建 / Models and builds** — 更新模型目录及默认元数据，修正用量条的热更新检查问题，并统一 Rust 格式。Refresh the model catalog and default metadata, fix the usage strip's hot-reload lint issue, and normalize Rust formatting.

## 验证边界 / Validation limits

- 自动化检查不替代桌面实机验收；Windows/macOS 安装升级、真实语音设备及上游 CLI 服务仍需按实际环境验证。Automated checks do not replace desktop acceptance; installation and upgrades, real voice devices, and upstream CLI services still require validation in their target environments.
- macOS DMG 和 Windows EXE 未签名，便携版的应用内更新仍使用安装包。The macOS DMG and Windows EXE are unsigned; in-app updates from the portable edition still use the installer.
