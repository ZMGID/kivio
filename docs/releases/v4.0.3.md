## 更新内容 / What's new

- 回答失败后可用原问题重试，同轮其他模型的成功回答会保留。自动重试上限统一为首次请求后再试 10 次。Retry a failed reply with the original question. Successful replies from other models in the same turn are kept. An initial request can be followed by up to 10 automatic retries.
- 回复显示整轮生成耗时。生成完成后，工作过程默认收起。窄窗口可在详情里查看完整工具命令。Replies show the duration of the full turn. Work details collapse when generation ends. Open the details to read the full tool command in narrow windows.
- 输入框显示附件文件名和图片编号，删除图片后会重新编号。聊天正文中单独成段的本地图片链接可显示缩略图。The composer shows attachment names and renumbers images when you remove one. A local image link in a paragraph of its own can show a thumbnail.
- 空对话在矮窗口中保持居中，空间不足时可向下滚动。更新了中性主题的明暗配色，并增加工作区按钮与分隔线的间距。Empty chats stay centered in short windows and scroll when space runs out. The Neutral theme has updated light and dark colors, and the workspace button has more room beside the divider.
- 修复 Windows 上外部 CLI 更新的版本识别与安装。OpenCode 按实际安装的包检查版本，默认路径的 Antigravity CLI 使用经校验的官方发行包更新，Hermes 增加版本查询回退。Fix version detection and installation for external CLI updates on Windows. OpenCode checks the installed package, default Antigravity CLI installations update from a verified official release, and Hermes has a fallback for version lookup.
