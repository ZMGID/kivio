# Kivio Desktop v4.0.3

## 更新内容

### OpenCode 2 与外部 CLI 更新

- **在 Kivio 中新装 OpenCode 时使用 OpenCode 2。** 通过 npm 或 Homebrew 已安装的版本继续沿原渠道检查和更新，OpenCode 1 用户仍可更新到 1.x 的最新版本。
- **Windows 支持在「本地 CLI 管理」更新默认路径的 Antigravity CLI。** Kivio 校验官方安装包的 SHA-512，确认新版可以启动并返回预期版本后再替换。更新完成后可以立即刷新版本。
- Windows 能识别 npm 生成的两类 CLI 启动器，兼容 Node.js 入口和原生可执行文件。Hermes 查询不到最新版本时，会尝试从官方发行页获取版本号。

### 回答失败后直接重试

- 当前一轮回答失败时，可在错误卡片下点 **重试**，用原问题重新生成。重开对话后，已保存的失败记录也能这样重试。一问多答中如果已有成功回复，Kivio 会保留这些回复并隐藏整轮重试入口。
- 遇到限流等可重试错误，首次请求失败后最多自动再试 10 次。旧配置升级后也使用这一规则。

### 查看整轮耗时和工具详情

- 工作过程标题显示**整轮生成耗时**，重开对话后仍能查看。能从历史时间戳估算的旧回复会加上 `≈`。
- 生成完成后，工作过程默认收起。正在查看中间步骤时，页面会保留阅读位置。聊天正文调整了字体和 Markdown 间距，窄窗口里仍能读清工具名，展开详情可查看完整命令。

### 多图附件和聊天窗口

- 输入框显示附件文件名和图片编号，编号与缩略图对应，发送后仍可查看。删除其中一张，剩余图片会按顺序重新编号。
- 聊天正文中单独成段的本地图片链接会显示带标签的缩略图，可点开看原图。预览加载失败时仍可使用原链接。
- 空对话在较矮的窗口里保持居中，空间不足时可滚动。中性主题更新了明暗配色和文字对比度，工作区按钮与面板分隔线也留出了间距。

## What's new

- **OpenCode 2 and CLI updates.** New OpenCode installations from Kivio use OpenCode 2. Existing npm and Homebrew installations keep their update channels. On Windows, Local CLI Management can update Antigravity CLI at its default path after verifying the official download and checking that the new executable reports the expected version. Kivio also recognizes both Node.js and native npm launchers. Hermes can fall back to its official release page for the latest version.
- **Retry a failed reply.** Select **Retry** below the error card to run the original question again, including after reopening a saved conversation. If another model already answered successfully in the same turn, Kivio keeps that reply and hides the turn-level retry. Retryable errors such as rate limits allow up to 10 automatic retries after the initial request, including after an upgrade.
- **Turn duration and work details.** The work header shows the elapsed time for the full turn and keeps it in history. Older estimates are marked with `≈`. Work details collapse on completion while preserving your place if you're reading them. Updated type and spacing make chat easier to read, and the expanded tool details show the full command.
- **Image attachments and layout.** The composer shows filenames and image numbers that match the thumbnails. Images renumber after removal, and sent images keep their numbers. Local image links in a paragraph of their own show labeled thumbnails that open the original images. Empty chats stay centered and scroll when space runs out. The Neutral theme has new light and dark colors, and the workspace button has more room beside the divider.
