# Kivio Desktop v4.0.3

## 聊天窗口的新配色和排版

- **中性主题更新了浅色和深色配色。** 浅色去掉了偏暖的底色，深色背景更深。正文、辅助文字、边框和强调色也一并调整，让不同层级的内容更容易区分。
- **长回答更好读。** 聊天主窗口和弹出对话优先使用平台界面字体，仍支持自定义字体。重新调整了 Markdown 标题层级、段距、列表缩进、引用和行内代码样式。带代码块的长回答在流式生成结束时也更稳定。
- **矮窗口里的输入框更容易够到。** 空对话在空间足够时保持居中，空间不足时可以滚动。打开右侧面板时，顶部工作区按钮与分隔线之间留出了间距。

## 看清这一轮做了什么、用了多久

- **生成结束后默认收起工作过程。** 如果你正在往上翻看某一步，页面会停在当前段落，点「回到底部」后再收起。
- **工具行支持分别展开详情和打开预览。** 窄窗口优先给工具名留空间，展开终端调用可查看完整命令。用 Tab 选中文件名或增删行数按钮，即可在工作区打开文件或查看改动差异。
- **`Worked for` 显示整轮生成耗时。** Kivio 内置聊天和外部 CLI 都会随回复保存实际耗时，重开对话后仍可查看。短任务支持毫秒和小数秒，长任务可显示小时。可以从时间戳估算的旧回复会标记 `≈`。

## 多张截图可以对着编号聊

- 添加多张图后，输入框末尾显示「图片 #1」「图片 #2」等标签，和缩略图上的编号对应。其他附件显示文件名。删掉一张图后，剩下的图片按顺序重新编号，发送后的缩略图也带编号。
- 助手把本地截图的链接单独放在一段时，聊天里直接显示带标签的缩略图。点击可看原图，预览失败时仍可打开原链接。

## 失败重试和外部 CLI 更新

- **原题重试。** 当前一轮失败后，可点错误卡片下方的「重试」。重开对话后，当前一轮已保存的失败也可这样重试。多模型同轮已有成功回答时，只显示错误并保留成功结果。限流等可重试错误在首次请求后最多自动再试 10 次，旧配置升级后也采用这个上限。
- **本地 CLI 维护。** 新装 OpenCode 使用 OpenCode 2，已有的 npm 或 Homebrew 安装沿原渠道更新。Windows 上可在「本地 CLI 管理」更新默认路径的 Antigravity CLI，校验官方发行包和新版启动结果后再替换。修复 Windows npm 启动器识别和安装结束后立即刷新版本的问题。Hermes 查不到版本时会尝试从官方发行页读取。

## What's new

- **Chat appearance.** The Neutral theme has revised light and dark palettes with clearer text contrast. Chat windows use platform fonts by default and still support a custom font. Markdown headings, paragraphs, lists, quotes, and inline code have revised spacing and styling. Empty chats stay centered when there's room and scroll in short windows. The workspace button has more room beside the open panel.
- **Work details and turn duration.** Work collapses when a reply finishes. If you've scrolled up to read an earlier step, Kivio keeps that paragraph in view until you return to the bottom. Narrow tool rows give the tool name priority, and expanded terminal details show the full command. Use the keyboard to open a file or diff in the workspace. The `Worked for` header shows the saved duration of the full reply for built-in chat and external CLIs. Estimates for older replies are marked with `≈`.
- **Numbered images and local previews.** The composer shows attachment names and image numbers that match the thumbnails. Removing an image renumbers the rest, and sent thumbnails show their numbers too. A paragraph of local image links displays labeled thumbnails that open the originals. The links remain usable if the preview fails.
- **Retry and CLI fixes.** Retry uses the original question and works for saved failures in the latest turn. If another model already answered successfully, Kivio keeps that reply. Retryable errors allow up to 10 automatic retries. New OpenCode installations use OpenCode 2, and existing installations keep their update channel. On Windows, Kivio can update Antigravity CLI at its default path, recognizes both npm launcher types, and can refresh the version right after an update. Hermes falls back to its official release page when needed.
