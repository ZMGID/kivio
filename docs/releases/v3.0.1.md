# Kivio Desktop v3.0.1

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows 安装包 / Installer** — `Kivio.Desktop_3.0.1_x64-setup.exe`（NSIS）
- **Windows 便携版 / Portable** — `Kivio.Desktop_3.0.1_x64-portable.zip`，解压后运行 `Kivio Desktop.exe` / unzip and run.
  - 需要 Edge WebView2，设置和对话与安装版共用。Requires Edge WebView2; settings and conversations are shared with the installed app.
  - 应用内更新仍下载安装包。In-app updates download the NSIS installer.
- **macOS** — `Kivio.Desktop_3.0.1_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`。
  - First launch: right-click → Open, or run the command above.

## 新版本亮点 / What's New

以下是 **v3.0.0 → v3.0.1** 的变更。These changes cover **v3.0.0 → v3.0.1**.

### 作品 / Works

- **加载与打开 / Loading and opening** — 作品页先显示已有索引，再补齐历史内容；返回页面保留列表，切入时不再闪烁。点击作品直接用系统默认应用打开，移除内置预览与卡片正文读取；历史版本仍可从菜单打开。Show indexed works before importing older content, retain the list when returning, and avoid the entry flash. Open files in the system default app instead of an in-app viewer or reading text for card covers; older versions remain available from the menu.
- **批量操作 / Batch actions** — 同名文件批量另存时自动编号，避免覆盖目标目录中的文件；部分版本删除失败时继续处理其余版本并刷新列表。Number same-named bulk exports without overwriting existing files; continue and refresh after a partial batch-delete failure.

### 聊天 / Chat

- **长对话阅读 / Long conversations** — 稳定长对话滚动和虚拟行测量，向上阅读时保留位置；思考过程改为简洁单行预览，回复完成后工具过程自动收起。Stabilize scrolling and virtual row measurements in long conversations, preserve the reading position while scrolling upward, show a concise one-line thinking preview, and collapse tool processes after a reply finishes.
- **打开与键盘操作 / Opening and keyboard use** — 对话打开遮罩设置等待上限，避免慢媒体或持续布局更新让历史内容一直不可见；键盘聚焦时可操作思考栏。Bound the conversation opening mask so slow media or ongoing layout changes cannot hide history indefinitely, and make reasoning controls available on keyboard focus.

### 模型与文件 / Models and files

- **模型目录 / Model catalog** — 更新模型目录，并支持 Opus 5.5 的思考设置。Refresh the model catalog and support thinking settings for Opus 5.5.
- **SVG 文件 / SVG files** — 保留 SVG 附件的 MIME 类型和扩展名，避免打开或导出时被误认成其他文件。Preserve SVG attachment MIME types and extensions so opening and exporting use the correct file type.

完整变更 / Full changelog: https://github.com/ZMGID/kivio/compare/v3.0.0...v3.0.1

## 后续修复（已纳入 v3.1.0） / Subsequent fixes (included in v3.1.0)

- **附件清理 / Attachment cleanup** — 按会话附件目录统一对账相对文件名与绝对路径，避免删消息或回退时误删仍被引用的 PDF 等生成文件；保留空引用时不删除、用户上传不参与自动清理的保护。Resolve relative names and absolute paths against the conversation attachment directory so message deletion and rewind preserve referenced generated files; retain empty-reference and user-upload safeguards.
- **Codex 计划档 / Codex plan mode** — 续接已有原生会话时落实只读沙盒，每轮显式携带策略；切回工作区写重新解析并保留配置中的可写目录和网络权限，不更换原生会话 ID。Enforce read-only sandboxing when resuming an existing native session and carry its policy on every turn; restore configured writable roots and network access when switching back without changing the native session ID.
- **Claude Code 工具调用 / Claude Code tool calls** — 回包优先匹配声明工具名的精确大小写，仅在候选唯一时恢复大小写，避免大小写不同的 MCP 工具被调用错。Prefer exact declared tool names and recover casing only for an unambiguous match, preventing dispatch to a different case-distinct MCP tool.
- **Codex 异步答复 / Codex asynchronous answers** — 空白问题被过滤后，答复仍使用原始问题索引，不把后续问题的答案交给上一题。Preserve native question indexes after filtering blank questions so answers remain attached to the correct question.
- **模型库补充 / Model catalog additions** — 按 2026-10-04 官方资料补充 13 条记录，涵盖 GPT-6.1 Sol、Sonnet 5.5、MiniMax M3.1 Flash Preview、新托管模型、Step 5 Preview、Qwen Image 2.1 Pro 与 Cohere Embed 5；修正 MiniMax 既有输出上限，Sonnet 5.5 关闭前置思考改用 `between_tools`。Add 13 verified catalog entries, correct existing MiniMax limits, and use `between_tools` for Sonnet 5.5's Off setting. 来源、计价与访问限制见 [模型库调研记录](../research/model-database-2026-09-24.md#follow-up--2026-10-04) / see the research record for sources, pricing, and access restrictions.
- **待办状态 / Todo state** — 主聊天与独立窗口保留实时待办版本，旧对话读取不再把已更新的清单回滚；内置运行时执行工具后若仍有未完成待办，结束前最多追加一次收尾提醒，不无限重试。Preserve live todo revisions across stale conversation reads in both chat windows, and send at most one closing reminder when a tool-using run ends with unfinished items.
- **通过对话创建任务 / Create tasks via chat** — 定时任务与自动化列表新增「通过对话创建」，打开新对话并预填对应请求，保留手动创建入口；预填不会自动发送或创建任务。Scheduled task and automation lists can open a new chat with the corresponding request prefilled; manual creation remains available, and prefilling does not send the request or create a task.
