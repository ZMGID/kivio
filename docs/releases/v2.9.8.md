# Kivio Desktop v2.9.8

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows 安装包 / Installer** — `Kivio.Desktop_2.9.8_x64-setup.exe`（NSIS）
- **Windows 便携版 / Portable** — `Kivio.Desktop_2.9.8_x64-portable.zip`，解压后运行 `Kivio Desktop.exe` / unzip and run.
  - 需要 Edge WebView2，设置和对话与安装版共用。Requires Edge WebView2; settings and conversations are shared with the installed app.
  - 应用内更新仍下载安装包。In-app updates download the NSIS installer.
- **macOS** — `Kivio.Desktop_2.9.8_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`。
  - First launch: right-click → Open, or run the command above.

## 新版本亮点 / What's New

以下按功能整理 **v2.9.7 → v2.9.8** 的版本差异。This changelog covers the **v2.9.7 → v2.9.8** release range, grouped by feature.

### Goal 模式 / Goal mode

- **持续执行目标 / Persistent goals** — 新增 Goal 模式及目标卡片，支持跨轮次继续执行并查看目标状态。Add Goal mode and a goal card to continue work across turns and track its status.
- **完成状态与后续对话 / Completion and follow-ups** — 改善目标完成证据校验、控制操作与完成信息展示，后续对话可收起已完成目标。Improve completion-evidence validation, goal controls and completion metadata; follow-up messages dismiss completed goals.

### 聊天阅读与输入 / Reading and composing

- **标题导航 / Heading navigation** — 长回复支持 Markdown 标题导航，改善标题定位、首轮滚动跟随及多模型分栏内的跳转。Navigate long replies by Markdown headings, with more reliable anchors, first-turn following and navigation within answer columns.
- **多模型分栏 / Multi-model columns** — 多模型回复分栏充分利用可用宽度，改善并排阅读体验。Expand multi-model answer columns to the available width for easier side-by-side reading.
- **斜杠技能消息 / Slash-skill messages** — 修复调用斜杠技能时用户消息未被完整保留的问题。Preserve user messages when invoking slash skills.

### 外部 CLI 代理 / External CLI agents

- **Codex 异步问答 / Codex asynchronous questions** — 接入新版非阻塞问题卡，支持选项和自由文本，答复通过普通消息发送或排队。Support non-blocking question cards with options and free text; replies are sent or queued as ordinary user messages.
- **Pi 思考档位 / Pi thinking levels** — 支持 `max`，优先读取各模型的实际思考档位，避免显示不支持的选项。Support `max` and discover per-model thinking capabilities instead of offering unsupported levels.
- **Grok 权限确认 / Grok permission prompts** — 增加工具请求时确认选项，接通批准、拒绝和取消处理，并确保权限切换对常驻进程生效。Add host-side permission confirmation with approval, rejection and cancellation handling, and apply permission changes to resident sessions.
- **Claude Fable 5.1 / Claude Fable 5.1** — 更新模型目录及配置映射，并保持旧会话的供应商覆盖兼容性。Update the model catalog and configuration mapping while preserving provider overrides for existing conversations.

### 通知稳定性 / Notification reliability

- **通知默认关闭 / Opt-in notifications** — 完成通知改为默认关闭，由用户在设置中开启。Completion notifications are now disabled by default and can be enabled in Settings.
- **macOS 通知 / macOS delivery** — 改善通知授权与投递，隔离窗口查询和通知处理，减少对回复完成及界面主线程的影响。Improve native notification authorization and delivery, isolating window queries and notification handling from reply completion and the UI thread.
