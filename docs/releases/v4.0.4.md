## 新版本亮点 / What's New

- **在聊天里回答外部 CLI 的提问 / Answer CLI questions in chat.** 提问卡片支持单选、多选和自填，答案会回传给 CLI，已回答的卡片在重开对话后仍可查看。Antigravity 可恢复原生会话。Question cards support single choice, multiple choice, and custom answers. Replies go back to the CLI, and answered cards stay visible when you reopen a chat. Antigravity can resume its native sessions.
- **供应商额度和余额 / Provider usage and balances.** 在供应商设置查看支持的套餐额度和账户余额，在「使用限制」查看支持的 API Key 套餐用量。OpenCode Go 预设使用更新后的地址。See supported plan limits and account balances in provider settings, and API key plan usage under Usage Limits. The OpenCode Go preset uses the updated endpoint.
- **全局网络代理 / Global network proxy.** 在通用设置集中配置 Kivio 使用的网络代理。Configure Kivio's network proxy in General settings.
- **笔记和备份 / Notes and backups.** 改进笔记编辑与恢复，聊天全量备份包含笔记和记忆正文。Notes editing and recovery have been improved. Full chat backups include notes and the text of saved memories.
- **聊天工作区和附件 / Chat workspace and attachments.** 切换对话时保留工作区布局和标题栏的模型与状态，滚到底部时正确高亮最后一轮。修复图片附件的行内标签、粘贴和选中，以及失败后回退或重试留下空分支的问题。Switching chats preserves the workspace layout and keeps the model and status visible in the title bar. The turn navigator highlights the last turn at the bottom. Image attachment labels, pasting, and selection are fixed, along with empty branches after rewinding or retrying a failed turn.
- **离线翻译和本地 CLI / Offline translation and local CLIs.** 恢复截图替换翻译的离线包下载，修复 CLI 安装排队阻塞无关会话的问题。Downloads for offline screenshot replacement translation work again. Queued CLI installations no longer block unrelated sessions.
