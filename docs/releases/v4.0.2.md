- Windows 便携版 / Portable。需要 Microsoft Edge WebView2。解压后运行 `Kivio Desktop.exe`。Requires Microsoft Edge WebView2. Unzip and run `Kivio Desktop.exe`. [Kivio.Desktop_4.0.2_x64-portable.zip](https://github.com/ZMGID/kivio/releases/download/v4.0.2/Kivio.Desktop_4.0.2_x64-portable.zip)

## 新版本亮点 / What's New

- **CLI 对话导入 / CLI conversation import**。可在项目中导入 DeepSeek Harness、Antigravity CLI 和 Pi 的历史对话，并由原 CLI 在原工作目录续聊。Import DeepSeek Harness, Antigravity CLI, and Pi conversations into a project. Resume each conversation with its original CLI in its original working directory.
- **侧栏与工作区 / Sidebar and workspace**。侧栏显示对话运行状态。切换项目、新建对话或重开窗口时，工作区面板沿用最后一次手动开关。The sidebar shows conversation run status. The workspace panel remembers your last toggle across projects, new conversations, and reopened windows.
- **聊天输入与附件 / Composer and attachments**。修复输入栏的方向键行为，简化工具调用摘要和附件展示。点击本地文本引用可在右侧预览并跳到对应行。Fix arrow-key behavior in the composer and simplify tool summaries and attachment display. Select a local text reference to preview the file at the cited line in the right panel.
- **用量与历史 / Usage and history**。简化上下文用量展示并修复压缩后的分隔线。历史会话索引按需建立。Windows 上的 Antigravity CLI 额度面板显示账号和套餐。Simplify context usage and fix the divider after compaction. Build the history index on demand. The Antigravity CLI limits panel on Windows shows the account and plan.
- **Windows 更新 / Windows updates**。随安装包发布 SHA-256 摘要，应用内更新会在启动安装器前校验下载内容。Windows installers ship with a SHA-256 digest. The in-app updater checks the download before launching the installer.

本版也包含自 v4.0.0 以来的代理与模型选择、内置专家、供应商登录和长对话加载改进。This release also includes the agent and model picker, built-in experts, provider sign-in, and long-conversation loading improvements since v4.0.0. [此前改动 / Earlier changes](https://github.com/ZMGID/kivio/blob/v4.0.1/docs/releases/v4.0.1.md)
