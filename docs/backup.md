# 备份与恢复

设置 → 备份与同步 → 本地备份可导出和导入 JSON 配置备份。

备份包含设置、供应商与模型、API Key/OAuth、全部助手和集配置。沿用原 `settings-backup` 格式，不包含对话、附件、项目文件、工作目录或 Git 工作树。

备份含未加密凭证，应仅在可信设备间传递。配置导入覆盖设置，按原 ID 合并助手和集，并立即生效。默认导入停用 MCP 和 hooks，保留本机外部 CLI 配置；仅在确认备份可信时勾选保留执行权限。导入沿用设置版本检查和失败回滚。

旧版 `.kivio` 完全备份不再提供导出和恢复。已有本地文件和远程文件保持原样。启动不会继续旧版暂存恢复，也不删除 `.restore` 或 `.before-restore` 目录。仅在当前应用数据目录缺失、且存在 `.before-restore` 时，将原数据目录移回；若只剩暂存的新数据，则报告错误，要求手动找回原数据。

## WebDAV 手动备份

设置 → 备份与同步 → 云端备份：点击“配置 WebDAV”，选择服务后填写服务器地址、远程目录、账号和密码（服务商要求时使用应用密码）。先测试连接，再保存配置。连接测试会创建目录，写入、重命名、回读并删除一个小型测试文件；服务端需支持 MKCOL、PUT、MOVE、GET、PROPFIND 和 DELETE。默认验证 HTTPS 证书，不跟随重定向；遇到重定向请填写最终服务地址。

点击“上传备份”上传 JSON 配置，内容和本地导出相同。每次上传使用 UTC 时间与随机标识生成独立文件名；先上传 `.partial` 文件，成功后才发布到备份列表。失败时尝试清理临时远程文件，残留 `.partial` 不会列为可恢复备份。上传和下载的单文件上限为 64 MiB。

点击“恢复备份”打开远程列表。列表只显示 `kivio-configuration-*.json`，按修改时间排序，支持刷新、恢复和删除。旧版完全备份不显示，也不能通过下载或删除命令操作。

恢复前会确认覆盖范围，默认不信任远程备份的执行权限。恢复沿用配置导入的版本检查和失败回滚，下载临时文件在成功或失败后清理。远程删除需要确认，且无法撤销。本功能只提供手动备份和恢复，不做双向同步或自动备份。

WebDAV 配置仍保存在应用数据目录旁的 `<应用数据目录名>.webdav.json`，不纳入配置备份。密码不回传到前端，未修改密码框时保留已保存值；主动清空后保存会清除密码。该文件和备份均含未加密凭据，请使用可信的 HTTPS 服务并保护本机账户。HTTPS 保护传输，不代表远程文件已加密。

### 服务填写与兼容性边界

- **坚果云**：地址 `https://dav.jianguoyun.com/dav/`，账号填写注册邮箱，密码使用「安全选项 → 第三方应用管理」生成的应用密码。官方当前说明默认单文件上限为 500M，单次列表最多返回 750 个文件和目录；Kivio 尚未实现其扩展分页，不保证超过该数量时列表完整。建议使用独立备份目录。[官方说明](https://help.jianguoyun.com/?p=2064)
- **Nextcloud**：从文件设置复制个人 WebDAV 地址，形如 `https://cloud.example.com/remote.php/dav/files/USERNAME/`，使用应用密码；本流程针对个人文件地址，非公开分享链接。[文件协议说明](https://docs.nextcloud.com/server/stable/developer_manual/client_apis/WebDAV/basic.html)
- **群晖**：启用 WebDAV Server，HTTPS 默认端口为 5006。服务器地址应包含已有、可读写的共享文件夹；证书必须可信且匹配域名。[连接排查](https://kb.synology.com/en-my/DSM/tutorial/How_to_fix_WebDAV_connection_issues)
- **自定义服务**：需要支持前述方法，尤其是 MOVE（发布临时上传）与 DELETE（清理和删除）。不支持 MOVE 的服务当前不能完成上传，不降级为直接暴露未完成文件。

切换服务会清空上一服务的地址、账号和密码；自建服务使用地址示例作为提示，不把示例当成真实服务器保存。已存在目录遇到 MKCOL 405/409 时，以 Depth=0 PROPFIND 验证同一地址确实为 collection 后复用；空的、不支持的文件大小属性不会使整个列表失败。409、413、429 分别提示目录/权限、文件大小与请求频率问题。

### 参考实现核对（2026-10-16）

核对 Cherry Studio `825b4d3` 的 `src/main/services/WebDav.ts` 和 LiveAgent `85029b5` 的 `crates/agent-gui/src-tauri/src/services/webdav.rs`：前者通过 webdav 库检查目录并上传，后者在 MKCOL 冲突后探测目录；两者的连接测试主要检查可访问性。Kivio 保留包含写入、MOVE、回读、列表和删除的连接测试，因此“测试成功”覆盖实际备份所需权限。源码比对与本地 HTTP 测试不等于真实坚果云、Nextcloud 或群晖账号验收。
