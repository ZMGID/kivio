# 备份与恢复

设置 → 基础 → 备份与恢复提供两种导出。

| 类型 | 内容 | 格式 |
| --- | --- | --- |
| 配置导出 | 设置、供应商与模型、API Key/OAuth、全部助手、集配置 | JSON，兼容原设置备份 |
| 完全导出 | Kivio 应用数据、对话与附件、项目和集、记忆、笔记、知识库、任务和运行记录、作品、托管插件、界面偏好、工作目录及项目文件 | `.kivio` ZIP 包，含版本清单与逐文件 SHA-256 |

两种备份都含凭证，应仅在可信设备间传递。配置导入覆盖设置，按原 ID 合并助手和集；完全恢复替换应用数据，不混入目标设备原有的对话。

## 完全备份

导出前停止正在执行的任务，将备份保存到应用数据、工作目录和项目目录之外。导出会检查文件新增、删除和内容变化；数据变化或文件不可读时失败，并保留之前的备份。当前上限为 128 GiB 未压缩数据、50 万个文件。

导入先在独立目录中校验格式、路径、大小和哈希，不立即修改当前应用数据。选择“重启并完成恢复”后，应用在加载任何数据和启动后台任务前替换数据目录。原数据保留在应用数据目录旁的 `.before-restore` 目录中；再次恢复时会为更早的副本增加唯一后缀。中断在两次目录重命名之间时，下次启动继续恢复。

项目和工作目录的文件恢复到应用数据目录下独立的 `restored-files` 子目录，并更新应用记录中的文件路径，不覆盖目标电脑上的现有项目。目录内部的符号链接展开为实际内容；指向备份范围外或形成循环的链接会报错，不静默忽略。

路径迁移和执行权限调整只修改 Kivio 管理的元数据。附件、项目文件及插件内容按原始字节恢复；即使文件名为 `.json`、`meta.json` 或 `workflow-hooks.json`，也不会作为应用配置解析或改写。

默认导入停用 MCP、hooks、插件和任务，并保留本机外部 CLI 配置。仅在确认备份可信时勾选保留执行权限。操作系统授权、外部应用登录、应用数据目录以外的 CLI 原生历史与运行环境仍需单独迁移；外部会话绑定保留原工作目录约束，不将显示历史转换成其他运行时的续聊上下文。

缓存、日志和 WebView 运行时目录不打包；界面偏好单独恢复，窗口坐标和尺寸保留目标电脑的值。恢复数据不恢复正在执行的进程。
